## A. Разделитель CSV

`wrong_sep` имеет форму (6, 1), а `example` — (6, 7). Файл разделён запятыми, поэтому при `sep=";"` pandas не находит ни одного разделителя и читает всю строку как одно значение: единственный столбец называется как весь заголовок («source_row,activity_year,lei,…»), а в ячейках лежат целые строки. Для этого файла нужен разделитель `,` (он используется по умолчанию). Ошибки при этом нет, поэтому результат чтения нужно проверять по `shape` и по имени столбцов.

## B. Частичное чтение

`nrows=3` ограничивает число читаемых строк: `preview` имеет форму (3, 7) — первые три записи (source_row 2, 3, 278), все семь полей. `usecols=["action_taken", "income"]` ограничивает столбцы: `small_columns` имеет форму (6, 2) — все шесть записей, но только два поля. `nrows` ограничивает чтение самого файла (остальные строки вообще не читаются), а `head(3)` берёт три первые строки из уже загруженной таблицы.

## C. Выбор столбцов

`example["action_taken"]` возвращает Series (один столбец, `type` — `pandas.core.series.Series`), а `example[["action_taken"]]` с двойными скобками — DataFrame из одного столбца. Выбор `selected` (список из трёх имён) тоже даёт DataFrame. `amount_view = example[["source_row", "loan_amount"]].head(2)` показывает две первые записи. `loan_amount` измеряется в долларах США (USD). Размер исходной `example` не изменился: после всех просмотров shape остался (6, 7), потому что выбор столбцов создаёт новый объект, а не меняет исходный.

## D. Маленький пример

Исходы шести строк: 1, 1, 2, 2, 3, 3.
- Одобрения: условие `action_taken ∈ {1, 2}`; 4 из 6 = 66,67 %.
- Выдачи: условие `action_taken == 1`; 2 из 6 = 33,33 %.

Ручная проверка по шести исходам совпала с расчётом. Эти доли относятся только к шести подобранным строкам и не описывают весь набор.

## E. Основной набор

| Показатель | Условие | Числитель | Знаменатель | Результат, % |
|---|---|---|---|---|
| Одобрения | `action_taken` ∈ {1, 2} | 6 139 | 6 830 | 89,88 |
| Выдачи | `action_taken` == 1 | 5 956 | 6 830 | 87,20 |

Доля одобрений — какая часть записей с исходами 1–3 была одобрена (кредит выдан или одобрен, но предложение не принято). Доля выдач — какая часть этих же записей закончилась выданным кредитом. Оба показателя относятся к `decisions.csv`: покупка жилья, Вашингтон (округ Колумбия, 11001), отчётный год 2023, 6 830 записей. На шесть подобранных строк из примера их переносить нельзя.

## F. Проверки

Проверено: набор не пуст; нет пропущенных исходов; все исходы входят в {1, 2, 3}; одобрения + отказы (6 139 + 691) = 6 830; 0 ≤ выдачи (5 956) ≤ одобрения (6 139) ≤ 6 830; обе доли лежат в диапазоне от 0 до 1. Такие проверки обнаружат неожиданные коды исхода, потерянные или задвоенные строки, неверное условие (например, выдачи больше одобрений) и неверный знаменатель (доля больше 1).
Роль пропущенного дохода для этих показателей: в `income` пропущено 342 значения, но для долей одобрений и выдач доход не используется — считается только `action_taken`, у которого пропусков нет. Строки с пропущенным доходом удалять не нужно: это изменило бы набор записей и знаменатель, и показатели стали бы относиться к другому набору.

## G. Исправление отчёта

В ноутбуке переменная `approval_rate` считалась как `full_outcomes.eq(1).sum() / full_n`. Это условие «только код 1», то есть доля выдач (87,20 %), а название обещает долю одобрений (коды 1 и 2, 89,88 %). Два исправления:
1. Название сохранено — условие исправлено: `approval_rate = full_outcomes.isin([1, 2]).sum() / full_n` → 89,88 %.
2. Условие сохранено — название исправлено: `origination_rate = full_outcomes.eq(1).sum() / full_n` → 87,20 %.

Название показателя должно совпадать с условием отбора и знаменателем: число несёт смысл только вместе с определением. Если назвать долю выдач «долей одобрений», читатель получит неверный вывод (занизит одобрения на 2,68 п.п.).

Результат описывает только эти опубликованные записи; он не показывает дальнейшие дефолты, одна запись не обязательно равна одному человеку, а данные модифицированы издателем для защиты приватности. Доли с шести подобранных строк (66,67 % и 33,33 %) на основной набор переносить нельзя.
