## H3. Инструменты

Series и DataFrame, пример: Series — один столбец с индексом, например `home_outcomes = home_decisions["action_taken"]`; DataFrame — таблица из нескольких столбцов, например `home_decisions` с формой (6830, 7). Выбор с двойными скобками `home_decisions[["action_taken"]]` тоже даёт DataFrame.
nrows и head, пример: `nrows` — параметр `read_csv`: он ограничивает, сколько строк прочитать из файла (`pd.read_csv(..., nrows=3)` читает только три строки). `head(3)` — метод уже загруженной таблицы: файл прочитан целиком, а на экране показаны первые три строки.
Метод и атрибут, пример: метод вызывается со скобками и что-то делает — `home_outcomes.value_counts()`, `home_outcomes.isin([1, 2])`; атрибут — свойство объекта без скобок — `home_decisions.shape` или `home_decisions.columns`.
Ссылка на документацию и что удалось уточнить: [pandas.read_csv](https://pandas.pydata.org/pandas-docs/version/2.2/reference/api/pandas.read_csv.html) — уточнил параметр `usecols`: он отбирает столбцы уже при чтении, поэтому в таблицу попадают только перечисленные поля. Это отличается от выбора `df[["a", "b"]]`, который выбирает столбцы из полностью загруженной таблицы.

## H+2. Типы значений — необязательно

Выполнялось: да.
Результаты сравнений и объяснение: в `text_example` столбец `action_taken` прочитан как строки. `eq(1)` сравнивает с числом: все значения False, количество True = 0. `eq("1")` сравнивает со строкой: True у двух записей, количество True = 2. Число 1 и строка "1" — разные значения, поэтому pandas не считает их равными. Сравнение должно отвечать типу прочитанных значений: для строк — `eq("1")`, для чисел (как в `decisions.csv`) — `eq(1)`.
